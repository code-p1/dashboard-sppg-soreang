# Dashboard Sebaran SPPG Soreang

Dashboard sebaran dapur SPPG (Makan Bergizi Gratis) di Kecamatan Soreang, Kabupaten Bandung.

- 20 dapur SPPG (18 operasional, 2 belum operasional), total 40.881 penerima manfaat
- Peta interaktif dengan titik Kantor Kecamatan Soreang (-7,027727, 107,516831)
- Jarak garis lurus dan radius dari kantor kecamatan ke tiap dapur
- Perencana inspeksi kecamatan (default: 5 tim, 1 hari, dasar pengurutan kelompok arah/wilayah)

Buka `index.html` untuk melihat dashboard, atau kunjungi situs GitHub Pages repo ini.
